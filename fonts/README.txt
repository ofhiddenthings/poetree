Put your font file here and name it:  Inter.woff2

Where to get it (free, open license):
- fontsource.org/fonts/inter  (download, then use the variable woff2 file,
  e.g. "inter-latin-wght-normal.woff2", and rename it to Inter.woff2)

Want a different font? Change the file name and the font-family name in the
@font-face block at the top of style.css. If the file is missing, the site
simply uses Helvetica or Arial, so nothing breaks.
